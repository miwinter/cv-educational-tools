Interactive Convolution Hyperparameters — Padding Modes

Light blue: zero padding. Red: current kernel window. Green: corresponding output cell.

  • valid: no padding.
  • same: output size = ceil(input size / stride). With stride 1, the input and output sizes match. Extra padding goes to the bottom and right when the total is odd.
  • full: kernel size − 1 padding cells on each side.

Keras Conv2D supports valid and same. full is included here as an additional convolution mode.
